# 🔋 Hari Battery Academy - Battery Technology Bot

> Founder: Batthari Hari AiTech | International Battery Academy

⚡ India's No.1 EV Battery Training Repository!

### 🎯 About This Project
This Bot is built for Battery Technology Training. It helps students learn about Lead-Acid, Lithium-Ion, LiFePO4, and EV Battery Technology.

📺 **YouTube:** https://youtube.com/@haribatteryacademy

### 🔋 Battery Technologies Covered
- ✅ Lead-Acid Battery - Service & Maintenance
- ✅ Lithium-Ion Battery Technology
- ✅ LiFePO4 (Lithium Iron Phosphate)
- ✅ EV Battery Pack Assembly
- ✅ Battery Management System (BMS)
- ✅ Battery Testing & Troubleshooting

### 🚀 Files in this Repo
- `app.py` - Main Battery Bot Application
- `requirements.txt` - Required Python Libraries

### 🛠️ How to Run This Bot?
1. Install Python
2. Run: `pip install -r requirements.txt`
3. Run: `python app.py`
